# CollabFlow (W.I.P)

CollabFlow is a digital, web-based visual workspace that lets multiple people simultaneously create, edit, draw, and organize content together on a shared canvas, regardless of their physical location. Unlike a traditional physical wall whiteboard or a single-user drawing app, it synchronizes changes instantly across all participants' devices via the internet

## Features:
- **Infinite Digital Canvas:** A limitless workspace where teams can pan, zoom, and map out sprawling ideas without running out of physical space.
- **Multiplayer Cursors:** Live cursors show the names and real-time movements of every collaborator currently on the board. **(W.I.P)**
- **Visual & Sticky Notes:** Virtual sticky notes, text boxes, freehand drawing tools, highlighters, and shapes.
- **Media & File Integration:** Ability to upload images, PDFs, documents, or embed cards from project management tools. **(W.I.P)**
- **Templates & Frameworks:** Built-in structures like flowcharts, Kanban boards, mind maps, business model canvases, and retrospectives. **(W.I.P)**
- **Interactive Tools:** Live timers, voting systems, reaction stamps, and comment threads to facilitate group decisions. **(W.I.P)**
# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Oxc](https://oxc.rs)
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/)

## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).

## Expanding the ESLint configuration

If you are developing a production application, we recommend using TypeScript with type-aware lint rules enabled. Check out the [TS template](https://github.com/vitejs/vite/tree/main/packages/create-vite/template-react-ts) for information on how to integrate TypeScript and [`typescript-eslint`](https://typescript-eslint.io) in your project.
